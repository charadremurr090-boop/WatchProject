# WatchProject

## Описание проекта

WatchProject - это прототип сайта для отслеживания и взаимодействия с виртуальными Smart часами.
Проект состоит из веб-интерфейса и локального сервера. Пользователь может зарегистрироваться, войти в аккаунт и в дальнейшем управлять привязанными часами.

# Стек проекта

## Frontend

HTML5,
CSS3,
JavaScript

## Backend

Python 3.14,
Flask 3.x

## База данных

SQLite 3

# Установка проекта

Перед запуском необходимо установить:

Python 3.14 или новее
  
Git

1. Клонируем репозиторий по ссылке: https://github.com/charadremurr090-boop/WatchProject

2. Установить зависимости pip install -r requirements.txt

3. Создать файл ".env" в папке Backend (см. файл env.example)

# Запуск проекта

1. Запустить сервер: python app.py

2. После запуска открыть браузер: http://127.0.0.1:8888
